# Recipe: Weekly review

1. **Clear:** get the inbox to zero (`recipe-triage`) and move loose notes into the vault.
2. **Get current:**
   - tasks;
   - calendar for last week and next week;
   - "waiting for" list (items pending on others);
   - projects without a next step.
3. **[W] For each active project, in parallel:**
   - status against the purpose card;
   - whether the purpose still holds;
   - the concrete next step.
4. **Usage for the week:** cost and number of sessions per recipe, taken from the session reports. Point out anything notable.
5. **Imagine:** review "someday / maybe" and the idea bank. If something is stuck, propose `recipe-unstuck`.
6. **◇ [U] Priorities for the week.**
7. **[D] Weekly plan** in `vault/weeks/<year>-<week>.md`, with adjustments in the tracker.
8. Run `session-close`.
